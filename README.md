Overview
This task focuses on analyzing machine failure datasets to identify patterns that lead to product breakdown. By identifying specific technical features, we can propose "fixes" through predictive maintenance and engineering design.

Machine Features Analyzed:
Thermal Factors: Monitoring Air and Process temperatures (K) to prevent overheating.

Mechanical Stress: Analyzing Rotational Speed (RPM) and Torque (Nm) to avoid motor strain.

Physical Degradation: Tracking Tool Wear (min) to ensure parts are replaced before failure.

The "Fix":
Implementation of a Predictive Maintenance System using IoT sensors. By setting thresholds for torque and temperature, the system can automatically shut down or alert an engineer before a "Power Failure" or "Overstrain Failure" occurs.

Deliverables:
Excel Sheet: A comprehensive dataset categorizing different failure modes and their physical causes.
